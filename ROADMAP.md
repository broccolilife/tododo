# Tododo — Product Roadmap

## Target Users
Mindful productivity seekers who want a calming, beautiful todo app that doesn't overwhelm.

## Competitive Edge
Healing-themed iOS app with aurora backgrounds, glass-morphism UI, and haptic feedback — todo meets self-care.

---

## P1 — Must Have (Next Release)
- [ ] Smart inbox with auto-categorization
- [ ] Recurring tasks with flexible schedules
- [ ] iCloud sync across devices
- [ ] Home screen & lock screen widgets

## P2 — Should Have (v2)
- [ ] Focus mode with ambient sounds
- [ ] Daily reflection / journaling prompt
- [ ] Task templates for routines
- [ ] Calendar integration (show tasks on calendar)

## P3 — Nice to Have (Future)
- [ ] AI task breakdown (big task → subtasks)
- [ ] Mood tracking tied to productivity
- [ ] Collaboration / shared lists
- [ ] Apple Watch quick-add and complications
